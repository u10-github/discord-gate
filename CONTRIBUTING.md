# Contributing

This project is published as an as-is OSS reference implementation.

## Contribution Policy

Pull requests are not accepted for normal upstream development.

Please do not open pull requests for:

- new features
- refactoring
- dependency updates
- documentation improvements
- project-specific deployment changes
- support requests

Such pull requests may be closed without review.

## Recommended Usage

Fork this repository and maintain your own copy.

This is intentional. Discord server operation, Cloudflare settings, Turnstile settings, and invite policy are environment-specific. A fork-first model avoids turning this repository into a shared managed product.

Suggested workflow:

1. Fork the repository.
2. Rename resources for your environment.
3. Review the security model.
4. Apply your own changes in your fork.
5. Operate and maintain your fork yourself.

## Issues and Support

Issues are not a guaranteed support channel.

The maintainer may not respond to:

- setup questions
- Discord permission questions
- Cloudflare deployment questions
- feature requests
- compatibility requests

For your own deployment, use your fork's issue tracker or internal operations notes.

## Security Reports

See `SECURITY.md`.

Security reports may be reviewed when possible, but fixes, releases, and response timelines are not guaranteed.
